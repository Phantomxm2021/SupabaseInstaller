# Task 7 Round 4 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make project creation and installation use one complete configuration aggregate, one explicit secret-action contract, and one authoritative Manager-owned port allocation path.

**Architecture:** The create wire model contains project identity plus the complete `configuration`; version, domain, site URL, and services come only from `configuration.general`/`configuration.services`. Manager validates and persists that aggregate, allocates all enabled server-owned ports transactionally, and installation fails closed on configuration-read errors. Update secret actions remain explicit (`retain`, `remove`, or `replace`) and the UI exposes nested validation errors.

**Tech Stack:** Go Manager/store/install tests, shared Go contracts, React Hook Form, Zod, TypeScript, Vitest, Vite.
